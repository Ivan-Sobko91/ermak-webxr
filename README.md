## 📱 Как запустить в режиме дополненной реальности (AR)

1. Откройте ссылку на мобильном устройстве (**Android** в браузере Chrome или **iOS** в Safari).
2. Нажмите кнопку **«👋 Посмотреть в вашей комнате (AR)»** в правом нижнем углу или **«📱 Режим AR»** в шапке.
3. Наведите камеру смартфона на горизонтальную поверхность (пол или стол) и немного перемещайте устройство для обнаружения плоскости.
4. Локомотив появится в дополненной реальности с сохранением масштаба, реалистичными тенями и физическим освещением!
5. При просмотре с настольного компьютера нажмите **«📱 Режим AR»** — откроется модальное окно с динамическим QR-кодом для быстрого сканирования смартфоном.

## ✨ Основные функции приложения

- **Google Model Viewer 3.5.0:** физически корректный рендеринг (PBR) на базе WebGL 2.0.
- **8 интерактивных хотспотов (аннотаций)** с подробным техническим описанием узлов:
  1. *Интерьер кабины* (пульт машиниста, светящиеся мониторы МСУД-Н и КЛУБ-У, кран № 395/215, кресла);
  2. *Задний межсекционный переход* (суфле, мостик, кабели-жоксы, рукава);
  3. *Кабина снаружи* (обтекатель, буферные огни, остекление);
  4. *Токоприемник ТАсС-10* (асимметричный полупантограф на 25 кВ);
  5. *Двухосная тележка* (тяговые двигатели НБ-514Б 835 кВт, колеса 1250 мм, рельсовый путь);
  6. *Автосцепка СА-3 и метельник*;
  7. *Осветительный комплекс* (прожектор и буферные фонари);
  8. *Высоковольтный выключатель ВОВ-25А*.
- **Быстрые ракурсы камеры:** переключение фокуса в 1 клик («Общий вид», «Интерьер кабины», «Задний торец / Сцепка», «Кабина снаружи», «Пантограф», «Тележка», «Сцепка», «Борт РЖД»).
- **Синтез локомотивного тифона Т-9:** двухтональный пневмогудок через Web Audio API (без внешних аудиофайлов).
- **Режимы освещения «День / Ночь»:** ночной режим с эффектом свечения фар и прожектора.
- **Информационная панель ТТХ:** выдвижная карточка с характеристиками 3ЭС5К.

## ⚙️ Характеристики 3D-модели

| Параметр | Значение |
| :--- | :--- |
| **Среда моделирования** | Blender 5.2 LTS |
| **Формат файла** | glTF 2.0 Binary (`.glb`) |
| **Размер GLB файла** | **~430 КБ** (ультрабыстрая загрузка) |
| **Полигонаж** | **9 216 треугольников (Tris)** (оптимально для WebAR) |
| **Интерьер** | Полнофункциональная кабина с пультами, экранами МСУД-Н/КЛУБ-У, креслами и шкафами |
| **Торец** | Межсекционный переход: суфле, откидной мостик, кабели-жоксы, задние фонари |
| **PBR-материалы** | Principled BSDF (Roughness, Metallic, Normal, Emission, Transmission) |
| **Ливрея** | Официальный стиль ОАО «РЖД» с логотипом компании на обоих бортах |
| **Поддержка AR** | Google Scene Viewer (ARCore Android), Apple Quick Look (iOS) |
